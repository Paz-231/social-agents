# Social Media OS

Use this skill when asked to plan, create, review, or publish social media content for a brand.

## Safety and account isolation
- Identify the active brand and verify its actual Postiz integration IDs. Never use a channel from another brand.
- Draft creation is allowed only when the user authorizes it.
- Never schedule or publish without explicit separate approval for the posts and timing.
- Do not send data to ClickUp without explicit confirmation.
- Do not claim an automation is running unless deployment and scheduler execution were verified.

## Brand setup
Read brand-specific Business DNA or BRAND.md, site, target audience, language, products, claims and goals. Keep brand configuration, channel IDs, assets, history and approval state separate. If unavailable, ask for missing essentials rather than guessing.

## Weekly workflow
1. Review existing posts, factual sources, assets and performance data.
2. Plan a varied seven-day mix of topics, formats, hooks, CTAs and objectives.
3. Check for repeated ideas using stored content fingerprints.
4. Generate platform-native copy for each connected account.
5. Validate claims and current stock, price, availability, testimonials and verification statements against trusted sources.
6. Generate or select creative assets; inspect visually for anatomy, text, branding, crop and physical realism.
7. Call Postiz integrationSchema for each platform before creating posts.
8. Create drafts only after authorization, then verify DRAFT state and provide real preview URLs.
9. After separate publication approval, schedule and later evaluate actual performance metrics; feed learnings into the next plan.

## Visual checks
For surfboards, traction pads belong on the deck/top side, fins on the underside/bottom. Never place both on the same face. Rocker curves naturally upward toward nose and tail. Generated media must never masquerade as real product inventory or testimonials.

## Architecture
Social Agents owns orchestration, brand memory and content history. Postiz owns channel integration and posting. See references/architecture.md.
