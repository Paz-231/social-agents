# AVB Creative Strategy Reference — adapted integration

This is an operational interpretation of five user-provided AI Video Bootcamp PDFs, not a reproduction of the source documents. The original PDFs are not committed. Source names: Advertising Psychology Playbook; Ad Scriptwriting Frameworks 2026; Hook Library; UGC Script Templates; Ad Strategy Guide 2026.

## Decision sequence
1. Define brand, verified offer, audience segment, desired action, organic vs paid and platform.
2. Assign awareness level: unaware, problem aware, solution aware, product aware, most aware.
3. For paid creative select objective: awareness, converting, retargeting. For organic content use education, discovery, trust, community interaction or conversion; do not pretend organic posts are paid retargeting.
4. Choose ONE primary customer desire and ONE central message. Assess market sophistication, current beliefs and objections.
5. Select one main narrative framework. Mix frameworks only when it improves clarity.
6. Generate three original hook options from curiosity, controversy, value/education, story/emotion or engagement; never copy library lines verbatim by default.
7. Draft shot-by-shot script, on-screen text, caption, CTA and proof requirements.
8. QA truth, compliance, visual realism and brand fit before saving as Postiz draft.

## Framework selection matrix
- SPARK / S.P.A.R.K.: social proof momentum; only with verified adoption and receipts.
- MYTH KILLER / E.X.P.O.S.E.: challenge a demonstrably false belief, not invented industry conspiracies.
- COUNTDOWN / S.T.A.C.K.: numbered, useful explanations; all list points must be true.
- ORIGIN STORY / B.U.I.L.T.: documented founder story, no fictional traction.
- SHORTCUT / E.S.C.A.P.E.: simpler path to a goal, with real mechanism.
- RAW TAKE / B.L.E.N.D.: natural, platform-native delivery; no deceptive fake customer voice.
- PRESSURE COOKER / W.O.U.N.D.: problem/tension/relief, without exploiting vulnerability.
- GRIT AD / 3 rules: simplify, low-fi presentation, contrast competitors; optional style filter.
- CONVICTION / S.T.E.E.L.: objection handling with verifiable evidence.
- FACE-OFF / R.I.N.G.: fair side-by-side comparison, no fabricated testing.
- BRIDGE / B.R.I.D.G.E.: goal, barrier, bridge, proof and action.
- CLIFFHANGER / L.O.O.P.: curiosity with honest payoff; no misleading hook.
- WITNESS / V.O.I.C.E.: only genuine permissioned testimonials, never synthetic customers represented as real.
- DEMO DROP / P.R.O.O.F.: real feature demonstrations; AI simulations must be labeled where relevant.
- TIME MACHINE / S.H.I.F.T.: before/after with genuine documented outcomes.
- EDUCATOR / T.E.A.C.H.: practical teaching first; best default for evidence-limited brands.

## Awareness routing (source strategy guide)
Unaware: education, story, native curiosity. Problem aware: problem explanation, useful relief. Solution aware: comparison, mechanism and demo. Product aware: proof and objection handling. Most aware: genuine offer and relevant next step. Paid retargeting requires actual audience/measurement setup; do not assume it exists.

## UGC formats (source UGC templates)
Unboxing; testimonial; day in my life; problem-solution; before/after; get ready with me; comparison/review; street interview; tutorial/how-to; story time.
Use templates as shot/story structures only. A generated actor is not an actual customer; never fabricate reactions, personal experiences, interviewees, product results or quotes.

## Psychology (source playbook)
Mass desire, market sophistication, beliefs, gradualization, intensification, identification, redefinition, mechanization, concentration and camouflage are hypotheses/creative lenses, not scientifically proven conversion guarantees. Prefer showing mechanism, honest trade-offs and meaningful alternatives over pressure tactics.

## Output schema per candidate
brand; channel; organic_or_paid; awareness_level; objective; customer_desire; core_claim; evidence_source; framework; hook_options[3]; selected_hook; scene_beats; voiceover; on_screen_text; caption; CTA; media_requirements; QA_flags; approval_status.

## QA gates
- No invented statistics, testimonials, credentials, endorsements, scarcity, savings, inventory, prices, comparisons or first-person experience.
- Avoid fake 'not sponsored' or 'this is not an ad' assertions.
- Check native platform media requirements, accessibility and readable safe zones.
- For surfing visuals: deck traction pad on top; fins underneath; plausible rocker rising at nose/tail; correct anatomy and equipment geometry.
- Brand DNA supersedes template style. Reuse content ideas only across brands when adapted and approved, never leak brand assets or account IDs.
- A framework may be skipped if not supported by real evidence.
- Draft creation only on user authorization; scheduling/publishing only with separate explicit approval.
